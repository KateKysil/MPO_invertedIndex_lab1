# Інструкція зі збирання та запуску проєкту ParallelInvertedIndex

## 1. Перелік залежностей
* **Платформа:** .NET 8.0 SDK (або новіша версія).
* **Пакет NuGet:** `UglyToad.PdfPig` (для вилучення тексту з PDF-файлів).

---

## 2. Команди збирання та параметри компілятора

Відновлення залежностей проєкту:
```bash
dotnet restore
```

Компіляція проєкту у режим продуктивності (Release):
```bash
dotnet build -c Release
```

**Опис параметрів компілятора:**
* `-c Release` (Configuration: Release) — вмикає агресивні JIT-оптимізації компілятора (інлайнінг методів, розгортання циклів, оптимізація регістрів CPU) та вимикає генерацію налагоджувальних символів.

---

## 3. Команди запуску та опис аргументів

### Варіант А: Інтерактивний режим (без аргументів)
```bash
dotnet run -c Release
```
Програма відобразить консольне меню для вибору режиму:
* `1` — Побудова зворотного індексу (послідовний запуск V0, V1, V2, V3 для $K \in \{1, 4, 16, 64, 256, 1024, 4096\}$, V4_Seq, V4_Tree);
* `2` — Дослідження хибного розділення (False Sharing);
* `3` — Послідовне виконання обидвох режимів.

---

### Варіант Б: Автоматичний запуск бенчмарку False Sharing
```bash
dotnet run -c Release -- --false-sharing
```

---

### Варіант В: Прямий запуск конвеєра побудови індексу з аргументами
```bash
dotnet run -c Release -- <datasetPath> <outputDir> <threadCount>
```

**Приклад:**
```bash
dotnet run -c Release -- ./dataset ./output 8
```

---

## 4. Опис аргументів командного рядка

| Позиція аргументу | Змінна в коді | Опис | Значення за замовчуванням |
| :--- | :--- | :--- | :--- |
| **`args[0]`** | `datasetPath` / прапорець | Шлях до директорії з вхідними PDF/TXT документами АБО прапорець `--false-sharing`. | `./dataset` |
| **`args[1]`** | `outputDir` | Шлях до директорії для збереження результатів (`results.csv`, `index_V*.txt`). | `./output` |
| **`args[2]`** | `threadCount` | Кількість потоків виконання $P$ для паралельних версій (V1–V4). | `Environment.ProcessorCount` |
